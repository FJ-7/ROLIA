# ROLIA

ROLIA is a company based in Salt Lake City, Utah, specializing in design and product fabrication.

# Description

The goal was to create a clean, minimal, responsive website that communicates the studio’s identity and services without unnecessary distractions.

# Technologies
- HTML5
- CSS3
- GitHub
- Google fonts

# Development

This project was built from scratch using HTML and CSS.
Git was used for version control, and Github for source code management and website publishing.

Live Website: https://roliastudio.com
