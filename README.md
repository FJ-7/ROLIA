# ROLIA
Rolia is a company based in Salt Lake City, UT specializing in design and product fabrication.

# description
The goal was to create a clean, minimal, responsive website that communicates the studio’s identity and services without unnecessary distractions.

# technologies
HTML5
CSS3
Github
Google fonts

This project was built from scratch using HTML and CSS.
Git was used for version control, GitHub for source code management, and Github pages for live site publishing.
The website is deployed at [roliastudio.com.](https://roliastudio.com)
